# Persistent parameter App example for the Crazyflie

This folder contains the app layer application for the Crazyflie to set and persist a parameter value using `paramPersistentStoreByVarId()`. The value is stored to EEPROM and restored automatically on the next boot.

See App layer API guide and build instructions [here](https://www.bitcraze.io/documentation/repository/crazyflie-firmware/master/userguides/app_layer/)
